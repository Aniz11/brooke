Настройка

1 · Будильник в «Часах»
  1. Открой Часы → Будильник → +
  2. Поставь время, например 06:00, в Повтор отметь все дни.
  3. В Звук выбери мелодию или «Выбрать песню» из Медиатеки. Нажми Сохранить.
2 · Автоматизация в «Командах»
  1. Нажми «Скопировать ссылку» ниже.
  2. Открой Команды → Автоматизация → +
  3. Выбери Будильник → «Выключен» → будильник «Любой» (или свой) → «Запускать немедленно» → Далее.
  4. «Новая пустая автоматизация» → «Добавить действие» → найди «Открыть URL-адреса».
  5. Нажми на поле «URL», вставь ссылку и нажми Готово.
…

Утром: выключаешь будильник → разблокируешь телефон → Brooke уже открыт в Safari.

3 · Важно
  1. Пользуйся Brooke в Safari. Добавь его в Избранное, чтобы быстро открывать.
  2. Не открывай его в режиме «Частный доступ» — там всё стирается.
  3. Открывай Brooke хотя бы раз в неделю, иначе Safari может удалить фото.
