# Brooke — будильник-мотиватор для iPhone

Тёмный минималистичный будильник:

1. **Звонок.** Играет твой трек, громкость нарастает. На экране слайд-шоу фото.
2. **Пример.** Чтобы выключить, нужно решить пример вроде 23 × 6. Ошибся — новый пример, музыка играет дальше. Кнопки «Отложить» нет.
3. **Видео.** Включается одно случайное видео. Пропустить нельзя.
4. **«Доброе утро».** Серия дней +1, если решил пример в течение 15 минут после звонка.

Фото, видео и трек ты добавляешь сам. Всё хранится только на телефоне.

---

## Как работает на iOS 18 и iOS 26

**iOS 18 (сейчас у тебя).** Фоновый режим.
- Вечером включаешь будильник и **сворачиваешь** Brooke свайпом вверх. Не смахивай его из списка открытых приложений.
- Приложение тихо работает в фоне, а в нужное время включает трек на полную. Звонит даже в беззвучном режиме.
- Если iOS всё-таки закроет приложение, каждые 30 секунд будут приходить запасные уведомления с первыми 29 секундами твоего трека. Они уже зависят от беззвучного режима.

**iOS 26 и новее.** AlarmKit.
- Звонит как системный будильник, даже если приложение закрыто.
- Кнопка «Встаю» открывает Brooke, и дальше всё идёт как обычно.
- Переход автоматический, ничего переделывать не нужно.

## Шаг 1. Собрать приложение на GitHub (бесплатно, Mac не нужен)

1. Зарегистрируйся на [github.com](https://github.com).
2. Нажми **«+» → New repository**. Название `brooke`, тип **Public**, затем **Create repository**.
3. На странице репозитория нажми ссылку **«uploading an existing file»**.
4. Распакуй архив и перетащи в окно браузера **всё содержимое** папки `Brooke`, включая папку `.github`. Нажми **Commit changes**.
5. Открой вкладку **Actions**. Сборка «Build Brooke» запустится сама и займёт около 10 минут. Если GitHub попросит, нажми кнопку включения workflows.
6. Когда появится зелёная ✓, вернись на главную страницу репозитория. Справа **Releases → Brooke — сборка 1 → скачай `Brooke.ipa`**.

Если сборка красная ✗, открой её, нажми на шаг с ошибкой, скопируй текст ошибки и пришли мне. Я исправлю.

## Шаг 2. Установить на iPhone через Sideloadly (Windows)

1. Установи **iTunes** и **iCloud** с сайта Apple. Нужны именно версии с сайта, **не из Microsoft Store**: так требует Sideloadly.
2. Скачай **Sideloadly** с [sideloadly.io](https://sideloadly.io) и установи.
3. Подключи iPhone кабелем. На телефоне нажми «Доверять этому компьютеру».
4. Перетащи `Brooke.ipa` в Sideloadly, введи свой Apple ID и нажми **Start**.
5. На iPhone открой **Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять**.
6. Включи **Настройки → Конфиденциальность и безопасность → Режим разработчика**. iPhone перезагрузится, после этого подтверди включение.

### Продление раз в 7 дней

С бесплатным Apple ID приложение работает 7 дней. Продлевай раз в 5–6 дней.

- **Вручную.** Подключи iPhone, снова нажми **Start** в Sideloadly. Все настройки, фото и серия сохранятся.
- **Автоматически.** В iTunes на вкладке iPhone включи «Синхронизировать с этим iPhone по Wi-Fi», а в Sideloadly включи автообновление. Компьютер должен быть включён и в той же Wi-Fi сети.
- **Без компьютера.** Можно поставить **SideStore**: он продлевает приложения прямо на телефоне.

## Шаг 3. Первая настройка

1. Открой Brooke и **разреши уведомления**. Это запасной сигнал, он важен.
2. Нажми ⚙︎ (справа вверху).
   - **Время** будильника.
   - **Музыка.** Сначала сохрани mp3 в приложение «Файлы», например из Telegram: открой трек → «Поделиться» → «Сохранить в Файлы». Потом в Brooke нажми «Выбрать трек».
   - **Фото.** Сохрани фото в галерею iPhone, потом нажми «Добавить фото из галереи».
   - **Видео.** Так же: сначала в галерею, потом «Добавить видео».
3. Нажми **«Проверить: зазвонит через 10 секунд»**, сверни приложение и заблокируй экран. Должна заиграть музыка.

## Каждый вечер

- ✅ Будильник **включён** на главном экране.
- 🔊 Громкость **выше половины**. Brooke предупредит, если звук тихий.
- 📱 Brooke **свёрнут, но не смахнут** из списка приложений.
- 🔌 Лучше поставить телефон **на зарядку**: фоновый режим немного тратит батарею.
- 🌙 Если пользуешься фокусом «Сон» или «Не беспокоить», добавь Brooke в разрешённые приложения, чтобы проходили запасные уведомления.

## Для разработчика

- SwiftUI, iOS 18+, без сторонних библиотек. Проект генерируется XcodeGen из `project.yml`.
- `Brooke/Core/AlarmEngine.swift` — логика будильника, фоновый режим, запасные уведомления, серия.
- `Brooke/Core/AlarmKitBridge.swift` — AlarmKit для iOS 26+. Если эта часть не собирается, workflow сам пересоберёт приложение без неё (флаг `NO_ALARMKIT`).
- `Brooke/Views/` — экраны: главный, настройки, утренний сценарий (фото и пример → видео → «Доброе утро»).
